🔄 STATE MANAGEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

App.jsx manages:
  • currentPage      - Page navigation state
  • cartCount        - Shopping cart counter
  • Navigation logic - Route between pages

Dashboard.jsx tracks:
  • products         - Product list from API
  • loading          - Loading state
  • error            - Error state
  • cart             - Local cart items

InventoryPage.jsx manages:
  • products         - Product list
  • showForm         - Form visibility
  • editingId        - Product being edited
  • formData         - Form inputs
  • filterCategory   - Active category filter
  • searchTerm       - Search input

CartPage.jsx handles:
  • cartItems        - Items in cart
  • Quantity changes - Update quantities
  • Price calculations - Subtotal, tax, total

🎯 USER INTERACTION FLOWS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FLOW 1: Browse Products
  1. User lands on Dashboard
  2. Products load from API
  3. Product cards display with hover effects
  4. User can view stats and filters
  5. Click "�� Add" to add to cart

FLOW 2: Manage Inventory
  1. User clicks 📦 in header
  2. Opens InventoryPage with table
  3. Can add, edit, or delete products
  4. Form validates inputs
  5. Changes sync to database

FLOW 3: Shopping
  1. User adds items to cart
  2. Click 🛒 icon to view cart
  3. Adjust quantities
  4. See real-time price calculations
  5. Review order summary
  6. Proceed to checkout

FLOW 4: Search & Filter
  1. Use search bar in header
  2. Use category filter on inventory
  3. Results update in real-time
  4. No page reload needed
